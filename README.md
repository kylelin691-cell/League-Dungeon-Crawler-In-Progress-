# League-Dungeon-Crawler-In-Progress-
A Top-Down 2D dungeon crawler where the user plays as traditional champions from League of Legends. 

11/13/26 - Version 1
I started this project at few weeks after I started learning java. I had heard from somewhere that building a project that I had interest in was a great way to learn. So here we are! This project is inspired by League of Legends and rougelike Dungeon Crawler games. I took two my favorite concepts and decided to mush them into one. This is the abomination of a game that came out of my idea! Its still a work in progress, and it defiantly wouldn't have been possible if i haden't relied on friends, the internet, and artificial intelligence. My hope is that as this project grows and refines, my knowledge and experience in Java will as well.
